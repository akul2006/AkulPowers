# FluxGrid OS - Smart Micro-Grid Energy & P2P Trading Engine

FluxGrid OS is a college Java + JDBC project that simulates a local renewable-energy micro-grid. Solar producers, consumers, EV stations and batteries can be monitored and can trade energy with each other.

## Final Architecture

Frontend (HTML + CSS + JavaScript)
→ Java Backend
→ JDBC
→ PostgreSQL

## Current ZIP

The frontend is complete as a clean demo interface. It uses simple in-browser demo data so the screens work before the Java backend is connected.

The `backend` and `database` folders are intentionally minimal placeholders. They are where the Java/JDBC code and PostgreSQL SQL scripts will be added next.

## Frontend files

- `frontend/index.html` — page structure
- `frontend/style.css` — visual design
- `frontend/app.js` — demo data and frontend interactions

No React, TypeScript, Vite, npm, pnpm, YAML, Replit files or generated UI libraries are required.

## How to run the frontend

Open `frontend/index.html` in a browser.

For development, a simple local HTTP server can also be used, but it is not required for the current demo.
